# 📖 Quran App

A simple and user-friendly Quran web application built with HTML, CSS, and JavaScript.

## ✨ Features

- 📖 Read Quran Surahs
- 🌙 Clean and simple interface
- 🔖 Bookmark verses
- ❤️ Favorite Surahs
- 🌐 Arabic and translation support
- 📚 Tafsir support

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
